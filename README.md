# 💼 Portfólio – Diego Ricardo Carvalho

Portfólio pessoal desenvolvido para apresentar meus **projetos, habilidades técnicas e trajetória como desenvolvedor**, com foco em uma interface moderna, responsiva e com boa experiência do usuário.

O site foi construído com tecnologias atuais do ecossistema front-end, priorizando **organização de código, componentização e performance**.

---

## 🚀 Tecnologias

- **React.js** – Biblioteca principal
- **TypeScript** – Tipagem estática
- **Vite** – Build e desenvolvimento rápido
- **Tailwind CSS** – Estilização utilitária e responsiva
- **AOS (Animate On Scroll)** – Animações ao rolar a página
- **Node.js / NPM** – Gerenciamento de dependências
- **Git & GitHub** – Controle de versão

---

## 📁 Estrutura do Projeto

```text
src/
├── assets/        # Imagens e arquivos estáticos
├── components/    # Componentes reutilizáveis
├── pages/         # Seções/páginas do portfólio
├── lib/           # Utilitários e configurações
├── main.tsx       # Ponto de entrada da aplicação
└── App.tsx        # Componente raiz
```
## 🧩 Componentização

#### O projeto segue uma arquitetura baseada em componentes reutilizáveis, facilitando manutenção e escalabilidade, como:

- Cards de projetos 

- Seção de habilidades

- Componentes de layout

- Seções isoladas por responsabilidade

## 🎨 UI & UX

- Layout totalmente responsivo

- Animações suaves e não intrusivas

- Hierarquia visual bem definida

- Efeitos de hover e transições

- Foco em clareza e navegação simples

## 🛠️ Executando o Projeto
```bash
# Instalar dependências
npm install

# Ambiente de desenvolvimento
npm run dev

# Build para produção
npm run build
```

## ☁️ Deploy

#### Projeto pronto para deploy em plataformas como:

- Vercel

- Netlify

- Cloudflare Pages

- Basta utilizar o build gerado pelo Vite.
